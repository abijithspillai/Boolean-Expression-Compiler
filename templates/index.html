Context-Free Grammar (CFG) Specification

Expression      → ORExpression
ORExpression    → ANDExpression ( '||' ANDExpression )*
ANDExpression   → NOTExpression ( '&&' NOTExpression )*
NOTExpression   → '!' NOTExpression | Comparison
Comparison      → Primary ( RelOp Primary )?
RelOp           → '>' | '<' | '==' | '!='
Primary         → IDENTIFIER | NUMBER | BOOLEAN | '(' Expression ')'

Operator Precedence & Associativity Hierarchy

Precedence Level Operators / Production Associativity Description
1 (Highest) ( ), Literals, IDs Non-associative Primary expressions and grouping parentheses
2 ! (NOT) Right-to-Left Unary logical inversion
3 >, <, ==, != Non-chaining Relational and equality comparisons
4 && (AND) Left-to-Right Conjunction of boolean conditions
5 (Lowest) || (OR) Left-to-Right Disjunction of boolean conditions

Language Type System & Semantic Invariants

Relational Operators (>, <)

Operands must both evaluate to number. Resulting expression type is boolean.

Equality Operators (==, !=)

Operands must be of compatible types (both numbers or both booleans). Resulting type is boolean.

Logical Operators (&&, ||)

Operands must both evaluate to boolean. Resulting expression type is boolean.

Unary NOT (!)

Operand must evaluate to boolean. Applying ! to a number triggers a semantic error.

How the Boolean Compiler Pipeline Works

1

Lexical Analysis (lexer.py)

Scans the input characters into tokens using longest-match recognition. Converts characters into token types: IDENTIFIER, NUMBER, BOOLEAN, GT, LT, EQ, NEQ, AND, OR, NOT, LPAREN, RPAREN.

2

Syntax Analysis (parser.py)

Uses recursive-descent parsing based on a Context-Free Grammar (CFG). Enforces operator precedence (Parentheses > NOT > RelOps > AND > OR) and constructs the Abstract Syntax Tree.

3

AST Construction (ast_nodes.py)

Creates strongly typed AST nodes: BinaryOpNode, UnaryOpNode, IdentifierNode, NumberNode, and BooleanNode.

4

Semantic Analysis (semantic_analyzer.py)

Traverses the AST with a Symbol Table to verify types. Prevents type mismatches like comparing numbers to booleans or applying logical operators to numbers.

5

Expression Evaluation

If all variables have sample values assigned in the symbol table, the AST is safely evaluated to produce a boolean result (true or false) without using Python's eval().
